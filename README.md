# Raw CMS Data

The raw CMS files are not redistributed in this repository. Download them from the CMS Marketplace Quality Initiatives download page and place them in this folder before running Notebook 01.

Notebook 01 expects these filenames:

- `PY2026 - Nationwide PUF.csv`
- `2025-QHPEnrolleeSurvey-PUF.xlsx`

The project also used the corresponding CMS data dictionaries and the QHP Enrollee Survey PUF Guide for variable interpretation.

Official CMS download page:
https://www.cms.gov/marketplace/about/health-insurance-quality-initiatives/downloads
