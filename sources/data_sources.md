# Data Sources

This project uses publicly available Centers for Medicare & Medicaid Services (CMS) Marketplace Quality Initiatives data.

## Primary datasets

- Plan Year 2026 Nationwide Quality Rating System Public Use File
- Qualified Health Plan Enrollee Survey Public Use File
- Corresponding data dictionaries and Enrollee Survey PUF Guide

## Official CMS pages

- Marketplace Quality Initiatives downloads: https://www.cms.gov/marketplace/about/health-insurance-quality-initiatives/downloads
- Quality Rating System: https://www.cms.gov/marketplace/about/health-insurance-quality-initiatives/quality-rating-system
- QHP Enrollee Survey: https://www.cms.gov/marketplace/about/health-insurance-quality-initiatives/enrollee-survey

## Reporting-unit grain

The analysis was performed at the reporting-unit level. A reporting unit was aligned across sources using issuer, state, and plan type.
